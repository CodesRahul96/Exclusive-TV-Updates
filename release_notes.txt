ExclusiveTV v1.0.53 Release

We are excited to bring you a significant update focused on stability, performance, and a modern user experience.

🚀 New Features & Enhancements

*   **Modern Check for Updates UI:**
    *   **New Top-Middle Card:** Experience a sleek, non-intrusive status card that slides down for background channel updates. No more blocking your view!
    *   **Professional Dialogs:** App version updates continue to use the premium centered dialog for maximum visibility.
*   **Enhanced Playback Support:**
    *   **Hotstar/Star Integration:** Native support for Star Playlists, including automatic DRM configuration and optimized HTTP headers for seamless streaming.
    *   **Robust Parsing:** Improved handling of JSON-based playlist structures (#EXTHTTP) for wider compatibility.

✨ UI & Performance Improvements

*   **Smoother Navigation:** Restored snappy focus animations and optimized input responsiveness (reduced debounce to 150ms).
*   **Sequential Channel Indexing:** Fixed critical indexing bugs to ensure every channel is correctly numbered and accessible.
*   **Stability Polish:** Resolved crash issues associated with category switching and rapid navigation.

🛠️ Fixes
*   Fixed "2456" channel ID bug.
*   Resolved duplicate highlighting in the category menu.
*   Improved background channel sync reliability.
