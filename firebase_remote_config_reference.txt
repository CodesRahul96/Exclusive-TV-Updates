Firebase Remote Config Parameter Mapping
=======================================

Store these keys and values in your Firebase Console under Remote Config.

1. main_api_url
   Value: https://exclusive-tv-app-api.vercel.app/
   Description: The primary link used to fetch the channel list and configuration.

2. api_host
   Value: https://raw.githubusercontent.com/CodesRahul96/Exclusive-TV-APP/
   Description: The primary source for the update.json file.

3. api_download_host
   Value: https://github.com/CodesRahul96/Exclusive-TV-APP/releases/download/
   Description: The primary host for downloading the APK update file.

4. api_host_fallback
   Value: https://raw.githubusercontent.com/CodesRahul96/Exclusive-TV-Updates/
   Description: The backup source for update.json if the primary GitHub repo is unavailable.

5. api_download_host_fallback
   Value: https://github.com/CodesRahul96/Exclusive-TV-Updates/releases/download/
   Description: The backup host for downloading the APK if the primary one fails.
